# InvoiceFlow Store — Desktop POS

Offline point-of-sale and inventory for Pakistani retail shops. Runs on one Windows PC and keeps working without internet.

## Download

**[Download the latest installer for Windows (64-bit)](https://github.com/HassaanMujtaba/invoiceflow-store-releases/releases/latest/download/InvoiceFlow-Store-0.1.0-win-x64.exe)**

All versions: [Releases](https://github.com/HassaanMujtaba/invoiceflow-store-releases/releases)

## Requirements

- Windows 10 or 11, 64-bit
- 4 GB RAM or more, 2 GB free disk space
- Internet for the first activation (then it works offline; it checks in now and then to renew the licence)
- A licence key from InvoiceFlow

## Install

1. Run `InvoiceFlow-Store-…-win-x64.exe`.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. (The installer isn't code-signed yet.)
3. Follow the installer. InvoiceFlow Store opens when it finishes.
4. Choose **New business on this PC** and enter your licence key.
   The first activation can take up to a minute.
5. Create the owner account and set up your shop.

Updates download in the background and install outside business hours, never during a sale.

## Moving to a new PC

Use **Backups & restore** (tray icon) on the old PC to make a backup, then pick **Restore from backup** during setup on the new PC. Contact InvoiceFlow if the licence needs to move to the new PC.
